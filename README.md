# Teacher Dashboard

A simple **Teacher Dashboard** project created using **HTML and CSS only**.  
This project is made for learning and practice purposes.

## Features
- Teacher dashboard interface
- Login page design
- Clean and simple UI
- Beginner-friendly project

## Technologies Used
- HTML
- CSS  
*(No JavaScript used)*
